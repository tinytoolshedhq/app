# 穩定背景資料

此目錄按需保存跨任務重用的產品事實、品牌語氣及地區規則，避免每次交接重述或重新調查。這是文件目錄，不是自動載入的記憶或模型快取。

## 撰寫與維護
- 每份文件聚焦一個主題，使用清楚的段落標題；依實際需要新增，不預先填入未確認的產品資訊。
- 記錄資料來源、適用範圍及最後確認日期。區分已確認事實、已採用決定與待確認事項。
- 已有權威來源時優先引用，不複製整份文件；背景變更時更新原文件，避免在多份摘要各自維護不同版本。
- 保留會影響執行的數字、日期、版本與限制。授權以本次使用者指示及任務記載為準，不能從舊背景推定本次已獲授權。
- 不保存密鑰、登入憑證、完整聊天歷史或逐步操作紀錄。

## 任務如何引用
任務提供必要背景的一句摘要，再指向實際檔案、完整 commit SHA 及相關段落。引用穩定背景時，不省略本次新增條件或尚未決定的問題。

收件 bot 先讀任務及指定段落；只有完成工作所需時才讀其他內容。需要查核的結論保留原始證據，不只依賴摘要。
