# 伸展與活動 App — 產品與內容規格

更新日期：2026-10-30。名稱暫定，平台僅限 iOS。

本文件與 `exercises.zh-Hant.json` 為第一版產品規格及內容草稿，尚未實作 App、後端、購買功能或下載服務。JSON 含 30 個動作內容單位；圖片、動畫與語音尚未製作，不能視為完整的影音下載包。

## 1. 產品目的

讓使用者打開 App，依當下姿勢、想活動的部位與活動時間，快速開始短時間伸展與關節活動。下載內容後，可戴耳機聽引導並離線跟做。

使用簡單線條／扁平向量人物示範，不採用真人拍攝。內容以日常活動為目的，不宣稱治療疼痛或提供個人復健處方。

## 2. 首頁與操作流程

依序點選：

1. 「你現在是？」：坐著、站著、躺著。
2. 「你想要活動哪裡？」：肩膀、胸口、上背、頸部、手部、手腕、手臂、腰部、髖部、膝部、腳踝、小腿或全身。部位名稱由 JSON 分類表提供，第一版採單選。
3. 「你想要活動多久？」：以 30 秒為最小單位；建議提供 30 秒、1、2、3、5 分鐘快捷選項。
4. 顯示符合條件的動作組合，按「開始」。

以本機持久化保存上次的姿勢、部位、時間與語音設定。下次開啟顯示上次選項，讓使用者直接開始或修改；不要只保存在記憶體。付費版另可儲存多組命名組合與順序。

第一版不提供 AI 自由文字選課、聊天推薦、Android 或鏡頭姿勢辨識。

## 3. 30 秒內容單位與播放

- 一個動作紀錄即一個 30 秒內容單位；下載資料包可以包含多個內容單位。
- 不將左側、右側拆成不同紀錄或分類。需要雙側的動作，換側與回正直接安排在同一個 30 秒內。
- 30 秒是完整活動時段，包含當段的簡短語音提示；不是每個維持姿勢都保持 30 秒。
- 使用者選的是「活動時間」，準備及固定間隔另計。首次可在開始前閱讀準備說明，按開始才啟動計時。
- 每個內容單位結束後固定停 3 秒。為符合「每包結束都停 3 秒」，最後一個單位也保留 3 秒結束緩衝，再顯示完成。
- 選擇活動 3 分鐘，播放 6 個單位；不計使用者暫停時，活動與固定間隔合計 198 秒，即 3 分 18 秒。
- 顯示「活動 3 分鐘，另有每段 3 秒間隔」，避免把活動時間標示為實際總時間。
- 3 秒間隔顯示下一個動作與準備姿勢；這不是保證使用者能在 3 秒內完成所有轉位，可隨時暫停。
- 播放中提供暫停／繼續、上一個、略過、靜音、目前進度與當段倒數。暫停時動畫、語音、倒數一起停，繼續時同步恢復。
- 切換動作、略過或耳機斷線時，先停止原語音；耳機斷線預設暫停，避免突然外放。
- iOS 鎖屏與背景音訊應繼續播放與計時；前景動畫依時間軸恢復。計時以時鐘與暫停累計計算，不依畫面更新次數或音檔長度。

## 4. 規則組合與分類

不需要 AI 參與選課。App 依已解鎖、已下載、已審核發布的內容進行篩選：姿勢相符 → 部位相符（全身不限部位）→ 所需器材可用 → 組合並排序。

第一版僅提供 30 秒倍數時間，單位數 `N = 活動秒數 / 30`。優先避免相鄰重複，偏好相同準備姿勢，尤其不要在躺姿單位間突然要求翻身或起身。本批躺姿全部為仰躺。

少量候選內容可明確提示「本次會重複部分動作」，組成多輪；不能悄悄加入不符合姿勢、部位或器材條件的動作。完全沒有符合內容時，顯示可下載或可解鎖的內容及修改選項。

「坐著」在本批資料指穩固無輪椅子；「躺著」指安全、平穩的仰躺表面，不代表任何床墊都適合。需要牆面等條件應顯示在預覽中，讓使用者確認或換動作。

30 筆包含同類活動的不同姿勢版本，讓三種情境都能使用；不是 30 種完全不同的生物力學動作。手指、腳踝等屬關節活動，因此定位為「伸展與活動」，不將全部標成靜態伸展。

## 6. 自訂 AI 語音

使用者可以輸入：「我希望用可愛、溫柔、稍微慢一點的方式和我說。」AI 僅調整聲音表現；第一版不即時改寫動作、方向、換側、注意事項與講稿，以維持指令一致。

流程：輸入語氣 → 後端生成短試聽 → 使用者確認 → 顯示本次動作清單與消耗 1 次 → 生成各提示音檔 → 檢查長度 → 下載 → 切換使用。

- 使用者不需要 API 帳號或 API Key；API 費用由開發者支付。
- 生成需要網路，下載完成後可離線播放。離線時可保存語氣草稿，不能宣稱已完成生成。
- 後端持有 API Key，不放進 iOS binary、前端環境變數或 JSON。
- 畫面清楚標示「AI 合成語音」，以短試聽讓使用者確認中文發音、口音與語氣。
- 動畫與音檔分開管理。更換語氣僅下載新音檔，不重下動畫。

### 一次轉換的建議界線

一次為「一種語氣，最多 10 個動作，生成的有效語音總長度最多 5 分鐘」。每動作活動時間固定 30 秒，不代表必須合成 30 秒連續講話。這是成本界線建議，正式推出前須用實測確認並在付款頁明列。

使用者有 30 個動作、想全部換成同一語氣時，先顯示分成 3 組、合計 3 次；未滿 10 個動作的一組也算 1 次。下載的預製語音、更換已存在語音、重新組合課程與重複播放都不扣次。

「一次轉換」不等於一次 API 呼叫；後端可能對多個動作、數段提示分別呼叫 API。「批次生成」只是安排多項工作，不代表使用供應商的 Batch API 或必然有折扣。

### 額度與失敗處理

後端綁定可恢復的使用者身分與已驗證購買交易，保存授予的 10 次及每筆消耗。具體登入方式待實作決定，但不能只靠本機計數。非消耗型買斷恢復時，不可重新發放已使用次數。

建立工作時原子預留 1 次，避免多裝置超額；相同請求用冪等鍵避免重複扣額。全部選定音檔完成、通過長度檢查且可下載時，才將預留轉為正式消耗。生成失敗則釋放預留；下載中斷保留工作與結果，重試下載不再次扣額。部分生成成功時不切換整組，新版完整可用前繼續使用舊版。

試聽也會產生成本，免費與付費均須有帳號級頻率、次數及長度限制；上限待成本測試後決定。已用完正式額度時停止提供新的付費語氣試聽，避免無法套用仍持續產生成本。

### 快取與語音節奏

快取以「動作 ID、講稿版本、語言、聲音、標準化語氣設定、模型版本」識別。快取相同的既有成果不用再次生成、不扣轉換額度；私人自訂文字與結果不擅自公開共享。後端和手機保存結果，預設語音可由所有使用者共用。

每個動作包含多段語音，各段有 `at_seconds` 和 `max_duration_seconds`。必須測量生成後的真實音長，不以字數或模型指令保證時長。超時先調整合成語速或重新生成，仍不合格則回退預製語音並標示失敗；不硬切掉動作重點，也不把當段延長超過 30 秒。

## 7. 成本與定價

Figma Starter 可先試做人物與動畫；超過方案功能限制才升級，價格依官方頁為準。Figma 是製作工具，發行後 App 不需連接 Figma。iOS 開發可使用 Xcode；本 repo 其他 App 使用 Expo，是否沿用 Expo/React Native 或採 SwiftUI 尚未決定，不影響本資料格式。

預算包含：Apple 開發者年費、適用的平台佣金、預設與自訂語音生成、試聽、失敗重試、後端、音檔儲存及下載。API 依實際合成量收費，離線重播不再產生生成費。供應商與模型需在實作時依當時可用性、費率與中文效果選定。

「售價 US$4、10 次生成合計 US$1」僅是先前的假設試算，不是供應商報價，也不是確定售價；剩餘 US$3 尚未扣其他成本。應以額度全數使用及試聽、重試情況實測定價，不假設使用者不會用完。

## 8. Figma 素材與動畫流程

1. 固定線條人物比例、線寬、服裝、視角與背景；依頭、軀幹、上臂、前臂、大腿、小腿等分層，建立可重用模板。
2. 依動作設定起始、過渡、目標、回正姿勢，審核關節位置與途中移動。
3. 在 Figma Motion 設定關鍵影格、旋轉支點、移動節奏、維持與回正；雙側動作在同一段編排。
4. 第一版使用無聲 MP4，另輸出靜態封面。簡單短循環適用於連續活動；維持型停在目標姿勢；含換側的動作可輸出完整 30 秒時間軸，不用不斷循環進出伸展。
5. 依 JSON 的 `animation_brief` 與 `movement_timeline` 製作，播放以 App 的 30 秒時鐘為準，動畫不得指示與語音相反的方向。
6. 先做 3 個代表動作，確認手機顯示、線條可讀性與檔案大小，再製作剩餘內容。
7. 參考官方來源與注意事項檢查動作與講稿，生成預設語音，測試所有提示音長及暫停／恢復同步，再打包發布。

不以單張 AI 生圖自動補間作為動作正確性的保證。當前 JSON 無圖片、GIF、MP4、音檔實體，素材欄位均為 `null`，不是無效的占位網址。

## 9. JSON 格式與資料包

檔案：`exercises.zh-Hant.json`，UTF-8、標準 JSON、繁體中文。

| 欄位 | 說明 |
| --- | --- |
| `schema_version` / `content_version` | 結構與內容版本 |
| `status` / `review_status` | 草稿與來源對照狀態；`source_referenced` 表示參考官方來源與注意事項，未經專業審核 |
| `categories` | 姿勢、部位、動作種類與器材的 ID／標籤對照 |
| `product_rules` | 30 秒、3 秒、買斷、10 次及無加購等規則 |
| `exercises` | 30 筆內容，坐姿／站姿／仰躺各 10 筆 |
| `position` / `body_regions` / `movement_type` | 分類，可對多個部位；不含左右側分類 |
| `equipment` / `setup` | 環境器材與準備敘述 |
| `description` / `instructions` / `cautions` | 畫面摘要、步驟與注意事項 |
| `movement_timeline` | 覆蓋完整 0–30 秒的動作段落，時間採左閉右開 |
| `voice_cues` | 定時語音、音長預算、尚待生成的音檔 |
| `animation_brief` / `media` | 動畫需求及待製作素材 |
| `access_tier` | `free` 或 `paid` |
| `source_ids` | 動作方向的參考來源，不代表來源認證本講稿或 30 秒安排 |

`body_regions` 不需為所有姿勢提供所有部位；UI 應依當前姿勢與可用內容顯示選項。完整封裝可用 manifest JSON 加圖片／影片／語音檔；發布時補上檔案路徑、大小、雜湊及版本。先下載到暫存位置，完成驗證後整包切換；失敗保留舊版，可續傳或重試。

資料更新會改變講稿版本時，不得拿舊語音配新動作時間軸；保留舊組或顯示需要更新。已保存組合引用穩定動作 ID，內容移除或無法使用時提示重新選擇。

## 10. 內容審核與驗收

本批是一般成人的輕度活動草稿，包含伸展與關節活動，參考官方來源（`source_ids` 所列 NHS 等）與注意事項；未經專業審核，也不是經個人評估的復健方案。來源的次數、維持時間並非本產品 30 秒設計。狀態為 `source_referenced`。

共同提示：穩固環境、自然呼吸、只在舒服範圍活動；若疼痛、麻木、暈眩或不適，立即停止。已有傷勢、手術後、懷孕或有活動限制者，先確認內容是否適合自身情況。不強迫完成動作，也不承諾 3 秒足以換姿勢。

發布前驗收：

- JSON 可解析、ID 唯一、分類參照有效、確實 30 筆，三種姿勢各 10 筆。
- 每段 30 秒，動作時間軸無空缺、重疊，語音音長不跨越下一提示或 30 秒邊界。
- 左右側指令包含在同一筆內容，圖片、動畫與語音方向一致。
- 所有圖片／影片／音檔存在，清單版本與雜湊吻合，草稿狀態不可誤發布。
- 飛航模式可播放已下載內容；鎖屏、背景、暫停、略過、耳機斷線後行為正確。
- 購買與恢復購買有效；10 次僅授予一次，並發／重試不重複扣額，零額度不能新生成。
- 無訂閱、無加購、無自動補額；用完仍可使用既有買斷功能與語音。
