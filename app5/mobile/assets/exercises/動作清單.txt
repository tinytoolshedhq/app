伸展動作庫：36 個內容單位，每個 30 秒
以下含同一活動的姿勢變體，並非全部都是靜態伸展。

- 手 / 前臂屈伸肌群 / 仰躺手腕勾放 (lie_wrist_flex)
  上臂支撐在身旁、前臂朝上，手腕小幅前後活動。
  語音：0s「上臂放穩，前臂朝上，手腕輕輕勾放。」；10s「只動手腕就好。」；15s「繼續小幅度活動，雙手不要靠近臉。」；25s「放鬆手腕，慢慢放下。」

- 手 / 前臂屈伸肌群 / 手腕上下活動 (sit_wrist_flex)
  前臂支撐在腿上，手腕小幅向上、向下活動。
  語音：0s「前臂放穩，手腕輕輕往上抬，再放下。」；10s「小小活動，不用彎到底。」；15s「繼續慢慢上下活動，手臂保持放鬆。」；25s「回到自然位置，休息一下。」

- 手 / 前臂屈伸肌群 / 站姿手腕活動 (stand_wrist_flex)
  雙肘彎曲靠身旁，手腕小幅向上、向下活動。
  語音：0s「雙肘靠身旁，手腕輕輕往上，再往下。」；10s「小幅度就好。」；15s「繼續慢慢活動，別用力彎到底。」；25s「放鬆手腕，雙手放下。」

- 手 / 手指屈伸肌群 / 仰躺手指開合 (lie_finger_open)
  雙臂放在身旁，雙手輕握拳再張開手指。
  語音：0s「雙手放身旁，輕輕握拳，再張開手指。」；10s「慢慢來，不用握緊。」；15s「繼續輕輕開合，肩膀保持放鬆。」；25s「停下，放鬆雙手。」

- 手 / 手指屈伸肌群 / 手指輕開合 (sit_finger_open)
  前臂放在腿上，雙手輕握拳再張開，慢慢重複。
  語音：0s「前臂放在腿上，輕握拳，再張開手指。」；10s「慢慢開合，不用握緊。」；15s「繼續照自己的速度，輕輕張開再放鬆。」；25s「停下來，放鬆雙手。」

- 手 / 手指屈伸肌群 / 站姿手指開合 (stand_finger_open)
  雙肘靠近身旁，手指輕握再張開，慢慢重複。
  語音：0s「雙肘靠身旁，雙手輕握，再張開手指。」；10s「不用握緊，慢慢來。」；15s「繼續輕輕開合，肩膀保持放鬆。」；25s「放鬆雙手，慢慢垂下。」

- 手臂 / 三頭肌 / 坐姿手臂後側伸展 (sit_triceps)
  坐直，左肘向上彎，右手輕扶。；回正放下後換另一手。
  語音：0s「坐直，左肘向上，右手輕扶。」；10s「肩膀放鬆，不用力壓。」；15s「雙手放下，再換右肘向上。」；25s「雙手放回腿上。」

- 手臂 / 三頭肌 / 頭上手臂後側伸展 (stand_triceps)
  左肘朝上彎曲，右手輕扶左肘。；輕靠近頭部，回正後換手。
  語音：0s「左手抬高彎肘，右手輕扶左肘。」；10s「保持呼吸，不要壓頸部。」；15s「放下換手，左手輕扶右肘。」；25s「慢慢放下雙手。」

- 手臂 / 二頭肌與三頭肌 / 仰躺手肘彎伸 (lie_elbow_bend)
  上臂放在身旁，前臂慢慢抬起再放回，手肘不鎖直。
  語音：0s「上臂留地，彎手肘，前臂抬起再慢慢放下。」；10s「不用把手碰到肩膀。」；15s「繼續輕輕彎伸，肩膀保持放鬆。」；25s「慢慢放下雙手，休息一下。」

- 手臂 / 二頭肌與三頭肌 / 手肘輕彎伸 (sit_elbow_bend)
  上臂留在身旁，雙手緩慢靠近肩膀再放下。
  語音：0s「手臂放身旁，彎手肘，雙手靠近肩膀。」；10s「再慢慢放下，不要甩手。」；15s「繼續輕輕彎曲，再慢慢伸回。」；25s「雙手放下，放鬆手臂。」

- 手臂 / 二頭肌與三頭肌 / 站姿手肘彎伸 (stand_elbow_bend)
  上臂留在身旁，雙肘緩慢彎曲、伸回。
  語音：0s「彎曲手肘，雙手慢慢靠近肩膀，再放下。」；10s「上臂留在身旁。」；15s「繼續慢慢彎伸，不用伸得很直。」；25s「雙手放下，放鬆手臂。」

- 肩 / 肩帶肌群 / 雙臂貼地輕滑 (lie_arm_slide)
  雙臂由身旁貼著平面向外滑，再滑回，不超過肩高。
  語音：0s「雙手沿地面往外滑一點，再慢慢滑回。」；10s「手臂不要超過肩膀。」；15s「繼續輕輕滑開再收回，不用勉強。」；25s「雙手回到身旁，放鬆。」

- 肩 / 肩帶肌群 / 肩膀輕繞圈 (sit_shoulder_circles)
  雙手自然垂放，肩膀小幅向前、向後繞圈。
  語音：0s「雙手放鬆，肩膀慢慢向前繞小圈。」；10s「輕輕繞就好，保持呼吸。」；15s「現在換方向，肩膀慢慢向後繞圈。」；25s「慢慢停下，放鬆肩膀。」

- 肩 / 肩帶肌群 / 雙臂向前輕抬 (stand_arm_raise)
  雙臂朝前緩慢抬起，最高不超過肩高，再放下。
  語音：0s「雙手朝前慢慢抬起，不超過肩膀，再放下。」；10s「輕輕抬，別聳肩。」；15s「繼續照舒服的高度，慢慢抬起再放下。」；25s「雙手放下，休息一下。」

- 肩 / 肩帶肌群 / 站姿肩膀繞圈 (stand_shoulder_circles)
  站穩後肩膀小幅向前、向後繞圈，雙臂自然垂放。
  語音：0s「雙腳站穩，肩膀慢慢向前繞小圈。」；10s「輕輕繞，別憋氣。」；15s「換方向，肩膀慢慢向後繞圈。」；25s「慢慢停下，放鬆肩膀。」

- 背 / 上背旋轉肌群 / 上半身輕轉 (sit_upper_back_turn)
  雙手交叉放胸前，骨盆朝前，上半身向兩側小幅轉動。
  語音：0s「雙手放胸前，上半身慢慢向左轉。」；10s「慢慢回到中間。」；15s「現在向右轉，轉到舒服的位置就好。」；25s「慢慢回正，放鬆雙手。」

- 背 / 上背旋轉肌群 / 肩胛輕收放 (stand_shoulder_blades)
  雙手垂放，肩胛骨輕輕靠近再鬆開，不夾緊或挺腰。
  語音：0s「雙手垂下，肩胛骨輕輕往後靠，再放鬆。」；10s「小小收一下就好。」；15s「繼續輕收再放鬆，不用力夾緊。」；25s「放鬆肩膀，自然站好。」

- 背 / 腰背肌群 / 屈膝小幅左右移 (lie_knee_roll)

  語音：0s「雙膝靠近，慢慢往左移一點，肩膀留地。」；10s「慢慢回到中間。」；15s「現在往右移一點，幅度小小的就好。」；25s「回到中間，雙腳踩穩。」

- 背 / 腰背肌群 / 骨盆輕輕回擺 (lie_pelvic_tilt)

  語音：0s「骨盆輕輕後傾，腰靠近地面，再放鬆。」；10s「臀部留地，別憋氣。」；15s「繼續小小後傾，再慢慢放鬆。」；25s「回到自然位置，休息一下。」

- 背 / 腰背肌群 / 坐姿側身輕移 (sit_side_reach)

- 背 / 腰背肌群 / 站姿側身輕滑 (stand_side_slide)

- 胸 / 胸大肌 / 胸前輕伸展 (sit_chest_open)

- 胸 / 胸大肌 / 站姿胸前舒展 (stand_chest_open)
